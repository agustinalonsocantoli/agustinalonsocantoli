### 👨‍💻 &nbsp;What I do

- 🏢 Full Stack at Imagina Group, a training company. I build the software the business runs on: a multi-tenant ERP, the ProAcademy e-learning campus, a CRM, invoicing tools and the Next.js marketing site
- ⚙️ Backend in AdonisJS and Express over PostgreSQL and MongoDB. Frontend in React with Vite and Next.js. Stripe for payments, Docker everywhere
- 🧱 The parts I care about most outlive any framework: clean architecture, tenant isolation and API design
- 🤖 AI features real users touch every day: a support bot for students, invoice data extraction, a server-monitoring agent on a local model

<br>

### 🤖 &nbsp;AI in production

- 🧠 **AI service layer in the ERP**: one interface, OpenAI behind it today. Swapping the provider means writing one adapter, so the product never depends on a single vendor
- 💬 **Student support bot**: an OpenAI assistant inside the ProAcademy campus that answers students where they study
- 📄 **aixtract**: AdonisJS service that turns invoices and documents into structured data with LLMs
- 🍎 **bot-guardian**: Python service on a Mac Mini that watches PM2 processes, applies deterministic rules first, then asks a local Qwen3-4B-Instruct (MLX on Apple Silicon, with my own LoRA adapter) to explain the incident and posts it to Discord
- 🔌 **Daily toolkit**: Claude Code with MCP servers for persistent memory and a code graph, plus n8n automations and a handful of Python and Discord/WhatsApp scripts
- 🧭 **How I work with it**: I design the system and review every line. The model does the typing. Fundamentals and architecture come first, frameworks and models after
